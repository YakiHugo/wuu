# Notion workspace plugin

Optional, disabled-by-default example using public Wuu extension contracts.

- [User guide and API limits](../../docs/en/customize/notion-workspace.md)
- [简体中文](../../docs/zh-cn/customize/notion-workspace.md)

Build from this directory with `npm run build`; run the built-runtime mocked-API acceptance flow with `npm run test:e2e`. The canonical manifest, desktop entry, and licensed SVG assets live in `internal/plugin/bundled/notion-workspace`; `dist/` and the local development manifest are generated.
