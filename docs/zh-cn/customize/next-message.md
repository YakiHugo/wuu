# 下一句建议

可选的 **Next message（下一句建议）** 插件会在正常完成回复后，预测你可能输入的一句话。插件内置但默认关闭。在 **设置 → 扩展** 中启用，再打开插件设置选择已配置的模型别名。

建议以灰字显示在已聚焦的空输入框内。**Tab** 只把建议填入草稿，不发送；发送前可以继续编辑。**Escape** 取消建议。输入文字、切换焦点或会话、开始新轮次、关闭插件都会取消待处理请求，过期结果不会写入草稿。斜杠命令和菜单保留按键优先级。没有建议时，Tab 保持原有焦点导航行为。

## 模型、数据和费用

模型别名留空时继承工作区已配置模型，不会自动选择专用低价模型。可按需填写已配置的低价快速模型别名。别名不可用时不显示建议，不会悄悄回退到其他模型。

每个符合条件的轮次最多尝试一次。请求上限为 4 秒、128 个输出 token，以及含预测提示词和 JSON 编码的 8 KiB UTF-8 输入。上下文过长时跳过，不截断消息。取消后仍可能产生提供商费用。请求成功也可以没有建议。

只把当前已完成轮次的用户显示文字和最终助手回复发送给所选提供商。不包含更早历史、未提交草稿、附件、工具输出和推理。插件不创建私有会话、不调用工具，也不读写笔记本。仅持久保存模型别名，不保存源对话文字；宿主和提供商正常的用量记录仍适用。

## 触发条件

插件启用期间，必须观察到同一轮次的实时开始和正常完成。恢复旧会话，或者在回复完成后才启用、重载插件，都不触发预测。失败、中断、内部、生成式、内容不完整或依赖附件的源轮次会跳过。输入框必须严格为空，且没有附件、排队消息或待处理输入。

支持已注册工作区和分屏；不支持侧会话和无项目会话。工作区 ID、事件路由根目录、会话和源轮次标识必须一致。输入变化会沿原始 promise 取消运行时及模型请求；重新聚焦不会重试已尝试的轮次。近期去重标识只保存在内存，作用范围是当前插件运行代次。

第一版刻意只使用当前一轮，以限制费用，避免把物理审计日志当作可见历史。它可能遗漏偏好和前文，建议也可能不准确。合成测试验证交互与取消链路，不代表真实模型的建议质量。
